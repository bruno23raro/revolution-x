API Oficial

Como a API oficial não publica em hora marcada, o agendamento guarda a intenção. Este card é o executor: processa os itens vencidos, publica pela Content Posting API e marca o resultado na própria fila. Falhas não encerram na hora: o item é reagendado com backoff exponencial (até 3 tentativas); só então vira failed terminal.

Disparo periódico: POST /api/cron/tiktok (gatilho de sistema multi-tenant, protegido pelo segredo CRON_SECRET). O registro do cron e a definição do segredo no hpanel são passos [HUMANO] — sem eles, use o botão abaixo.

⚠Aviso de risco
O TikTok não expõe coleta de seguidores/vídeos pela API oficial. O método "Sem API / Avançado" (scraping) viola os Termos de Uso, pode bloquear IP/conta e violar LGPD/GDPR.
