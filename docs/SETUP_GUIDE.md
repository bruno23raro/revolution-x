# SETUP_GUIDE.md — Para quem não é programador

## PASSO 1: INSTALAR (faz sozinho se quiser, ou me diga e eu faço)
Você não precisa editar código. Eu faço via terminal.

Se quiser, rode:
- `npm init`
- `npm install next react react-dom typescript tailwindcss`

Mas eu faço quando você confirmar.

## PASSO 2: CONECTAR BANCO (quando você quiser)
Diga:
- "Uso Postgres local" OU
- "Uso Neon (nuvem)" OU
- "Uso Render"

Eu crio a conexão sem você digitar código.

## PASSO 3: CONECTAR COMTA META / WHATSAPP (OBRIGATÓRIO PARA FASE 7-10)
Quando chegar isso, vou te mostrar a tela guiada:

AÇÃO NECESSÁRIA
Conectar Meta / WhatsApp

Clique:
[ABRIR CONFIGURAÇÃO META]

Faça login.
Autorize.
Copie o App ID / Token.
Cole aqui quando eu perguntar.

[CONCLUÍ — CONTINUAR]

Depois eu testo automaticamente.

## PASSO 4: NÃO INVENTO API
Nenhum endpoint é inventado.
Se não existe API oficial para algo, vou criar:
- Modo assistido (você faz no site da plataforma, eu preparo os dados)
- Fluxo guiado
- Aviso claro da limitação

## PASSO 5: SEMPRE TESTO ANTES DE AVANÇAR
Cada fase: implemento → testo → corrijo → avanço.
Nunca pulo.
