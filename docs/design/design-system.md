# Design system

## Tokens
Raio 8/12/16. Espaco 4/8/12/16/24/32/48. Fonte Inter, escala 12-48. Sombras 3 niveis.
## Cor
Neutro 50-950, primaria unica, semantica success/warn/danger, contraste AA minimo.
## Componentes
Button, Input, Field, Card, Dialog, Toast, Table, Tabs, Badge, Skeleton, EmptyState.
## Regra
Todo componente tem 4 estados: default, loading, erro, vazio. Dark mode por classe, nao por midia.
## Acessibilidade
Foco visivel, aria-label em icone, navegacao por teclado, contraste verificado.
